# 训练营 MOBA 对抗战场实施待办清单

> 关联资料：[完整实施计划](./训练营-MOBA对抗战场实施计划.md)、[实施进度台账](./训练营-MOBA对抗战场实施进度.md)、[战场参考图](../战场图.png)。

本清单将原计划转换为可连续执行的任务顺序。原计划中的规则、接口和验收条件仍是唯一的需求依据；本文件只拆分执行动作，不替代原计划。

## 使用规则

- `[ ]`：未开始；`[~]`：进行中；`[x]`：已完成；`[-]`：已确认不适用，并在进度台账中写明依据。
- 每次开始或完成一个阶段，都同步更新 `docs/训练营-MOBA对抗战场实施进度.md` 的当前断点、证据和下一步。
- 未完成阶段验收前，不勾选后续依赖任务；发现图片、代码或产品规则冲突时，先记录决策，再继续实现。
- 不根据当前工作区的未提交变更推定某个阶段已完成；必须以审计结果、测试结果和截图证据为准。

## 图例到实现对象的覆盖表

| 参考图对象 | 标注/配置产物 | 运行时对象 | 必须验证 |
|---|---|---|---|
| 战场有效边界与地图外区域 | `geometry.json` 边界多边形 | 可行走范围与相机边界 | 顶部图例不进入战场坐标 |
| 左右两侧上下四个三角高地 | `spawnRegions`、出生槽位 | 阵营出生区域和初始路线 | 左为进攻方，右为防守方 |
| 三条灰色横向道路与红/青方向箭头 | `routes`、`navigation.json` | 兵线中心线、路线偏好 | 三条路线跨中央区域连续 |
| 中央黄色纵向沙地 | `regions` 的沙地多边形 | 地形查询、路线连接和视觉材质 | 不是默认分割墙 |
| 黄矩形、黄半圆区域 | 独立沙地区域/营地/装饰标注 | 配置化地形或营地逻辑 | 不只按颜色合并 |
| 绿色草地和野区 | 草地区域 | 基础地面与可行走区域 | 道路外合法导航可查询 |
| 红/青八边形 | `objectives.json` 塔定义 | 塔碰撞、攻击和摧毁状态 | 位置、阵营、路线顺序正确 |
| 蓝色 `X` | `neutral-camps.json` 营地定义 | 中立单位生成与拉脱范围 | 每个标记都有对应营地 |
| 黑色尖刺墙 | 高墙多边形 | 强碰撞、导航和可选视线阻挡 | 不可穿过、不可投射规则可配 |
| 黑色弧线、半圆和封闭墙 | 普通墙路径与碰撞多边形 | 移动阻挡与局部绕行 | 不产生无形墙或穿墙 |
